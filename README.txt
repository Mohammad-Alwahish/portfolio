Portfolio files - instructions

1. Keep index.html and style.css in the same folder.
2. Project concept images are included in image/: sales.png, website.png, database.png.
3. Copy YOUR own images into the image/ folder, with these exact names:
   - me.jpg      (profile picture)
   - code.jpeg   (left About photo)
   - sleep.png   (right About photo)
4. Open index.html with VS Code Live Server.
5. For GitHub Pages, keep the home page named index.html.
6. Font Awesome icons load from a CDN, so they need an internet connection.
7. Project pictures are illustrative mockups, not screenshots of completed projects.
